# Blink Guard

Blink Guard — это легковесное кроссплатформенное приложение на Rust для мониторинга моргания и защиты зрения при длительной работе за монитором. 

Программа отслеживает лицо через веб-камеру, вычисляет трехмерный коэффициент открытия глаз (3D EAR), рассчитывает частоту морганий в минуту (BPM) и предупреждает звуковым сигналом и системным уведомлением, если пользователь долго не моргает.

Все нейросети вшиты непосредственно в исполняемый файл. Приложение распространяется в виде одного бинарника и не требует внешних папок с моделями.

---

## Основные возможности

* **3D Eye Aspect Ratio (3D EAR)**: Использование координаты глубины (Z) ключевых точек MediaPipe FaceMesh обеспечивает геометрическую инвариантность. Наклоны головы вперед и назад не приводят к ложным срабатываниям.
* **Защита от поворота головы (Yaw)**: Расчет ведется по максимальному значению между левым и правым глазом. При повороте головы в сторону перспектива одного глаза не провоцирует ложное детектирование.
* **Адаптивная динамическая база**: Порог срабатывания непрерывно подстраивается под текущую позу пользователя. При изменении положения тела или наклоне головы база плавно адаптируется за доли секунды, исключая дедлоки.
* **Физиологическая валидация по времени**: Длительность смыкания век измеряется через монотонные таймеры (`Instant`). События короче 65 мс (шум детектора) и длиннее 380 мс (прищур, микросон) отсекаются.
* **Двухэтапная калибровка**: Индивидуальный замер базового уровня открытых и закрытых глаз с применением медианной фильтрации, устойчивой к случайным морганиям в процессе настройки.
* **Анализ частоты морганий (BPM)**: Расчет морганий в минуту в скользящем 60-секундном окне для контроля зрительного режима (норма: 12-20 морганий/мин).
* **Оповещения о замирании взгляда (Stare Alert)**: Проигрывание звукового сигнала и отправка нативного уведомления ОС, если пользователь не моргает дольше 12 секунд.
* **Отслеживание присутствия человека**: При уходе из кадра таймеры замирания сбрасываются. Программа не подает ложных сигналов в пустую комнату и не срабатывает в момент возвращения.
* **Полная автономность (Standalone binary)**: Модели UltraFace и FaceMesh упакованы в бинарник через `include_bytes!`. Приложение можно перемещать в любую директорию.
* **Отказоустойчивое ускорение**: Автоматическая попытка инициализации аппаратного ускорения (DirectML / CoreML / CUDA) с прозрачным переключением на CPU при несовместимости библиотек или драйверов.

## Архитектура системы

Программа построена на многопоточной архитектуре без взаимных блокировок:

1. **Поток захвата камеры (`record.rs`)**:
   Захватывает видеопоток через `nokhwa` в нативном формате драйвера (V4L2 на Linux) с автоматическим перебором устройств и отсевом служебных узлов метаданных. Передает чистые RGB-буферы через ограниченный канал `crossbeam-channel`.

2. **Поток анализа (`analyzer.rs`)**:
   * Детекция лица моделью UltraFace (разрешение 320x240, повторный поиск каждые 6 кадров).
   * Сглаживание границ BBox и предсказание 468 ключевых 3D-точек моделью MediaPipe FaceMesh (256x256).
   * Вычисление 3D EAR и ведение машины состояний калибровки и адаптивной базы.
   * Контроль временных интервалов и генерация событий `BlinkEvent`.

3. **Основной поток интерфейса (`ui.rs`)**:
   Отрисовка легковесного GUI на базе `eframe` / `egui`. Отображение видеопотока, статистики FPS, текущего BPM, статуса присутствия лица и переключателей оповещений.

4. **Модуль оповещений (`notifier.rs`)**:
   Синтез аудиосигнала в памяти через `rodio` (без внешних аудиофайлов) и асинхронный вызов системных уведомлений через `notify-rust`.

## Системные требования

### Для сборки:
* Rust 1.75 или новее (cargo)
* Компилятор C/C++ (gcc / clang)

#### Зависимости для Linux (Ubuntu / Debian):
```bash
sudo apt-get update
sudo apt-get install -y libasound2-dev libdbus-1-dev libudev-dev libv4l-dev
```

#### Зависимости для Linux (Arch / Artix):
```bash
sudo pacman -S --needed alsa-lib dbus systemd-libs v4l-utils
```

## Сборка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/username/blink_guard.git
cd blink_guard
```

2. Убедитесь, что файлы моделей находятся в директории `models/` перед сборкой:
```text
models/
├── face_detector.onnx
└── face_landmarks.onnx
```

3. Соберите оптимизированный релизный бинарник:
```bash
cargo build --release
```

4. Готовый исполняемый файл находится по пути:
```bash
./target/release/blink_guard
```
Этот файл можно копировать на другие аналогичные системы — внешние файлы моделей ему больше не требуются.

## Использование

1. Запустите приложение:
```bash
./blink_guard
```
2. **Калибровка**:
   * Программа автоматически обнаружит лицо и начнет этап 1/2.
   * Смотрите на экран в естественной позе в течение 3 секунд (глаза открыты).
   * На этапе 2/2 закройте глаза на 2 секунды.
   * После калибровки трекер перейдет в рабочий режим.
3. **Управление в интерфейсе**:
   * Переключатели звука и системных уведомлений доступны в верхней панели.
   * Кнопка повторной калибровки позволяет сбросить базу, если изменилось освещение или расстояние до камеры.
